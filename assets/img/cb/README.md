# Control Bionics photography

Drop image files here using the exact names below. The site picks them up on the next page load. No rebuild is needed for the hosted version. Run `node tools/build.mjs` afterwards if you also want them embedded in `standalone.html`.

Until a file exists, the page tries the public image on controlbionics.com and falls back to the built-in illustration if that does not load.

Notes

- These images belong to Control Bionics. They are shown for discussion in a proposal addressed to Control Bionics, with credit in each caption.
- The product panel shows the whole image without cropping. The photo strip and the Instagram concept crop to fill, so pick photos where the sensor sits near the center.
- JPG, PNG and WebP all work as long as the file name and extension match the table.
